## 客户初始诉求（原话）

> "我们后勤科每天收几百条报修，靠人工看内容分给对应班组。新来的分不准，
> 老师傅又忙不过来。你们的 AI 能不能自动分派？最好还能预判哪些是急的。"

## 已知约束

- 数据不出内网，医院信息科明确不接受任何公有云 API
- 现有 HIS/设备台账是某厂商 2013 年的系统，只提供只读视图，无对外 API
- 后勤科一线 4 个班组：电气、给排水、医用气体、医疗设备
- 报修文本极不规范：大量方言表述、错别字、只写"坏了"的空描述
- 医用气体类报修属高风险，分派错误可能延误抢救

## 材料清单

- `interviews/` 三场情境访谈记录（每场只跟一位一线操作者）
- `data/` 报修工单样本与班组台账
- `constraints.md` 合规与预算边界
- `tasks.md` 分阶段任务书（六阶段，每阶段附提示与退出标准指引）
